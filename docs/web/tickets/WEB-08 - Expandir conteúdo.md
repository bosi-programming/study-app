# WEB-08 — Expandir conteúdo

**Tipo:** feature · **Épico:** Lista · **Depende de:** WEB-03

## Resumo

Expandir & recolher um cartão para ler o conteúdo completo.

## O que muda na tela

- Icon button "expandir" alterna o cartão; expandido exibe o Conteúdo abaixo do cabeçalho.

## Critérios de aceitação

- [ ] Icon "expandir" alterna entre colapsado & expandido.
- [ ] Estado expandido exibe o campo Conteúdo do cartão.
- [ ] Conteúdo vazio exibe um indicador.
- [ ] Icon button operável por teclado com `aria-label` (RNF-06).
