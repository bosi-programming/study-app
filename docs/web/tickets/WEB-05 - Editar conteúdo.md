# WEB-05 — Editar conteúdo

**Tipo:** feature · **Épico:** Lista · **Depende de:** WEB-04, CORE-04, CORE-05

## Resumo

Editar nome, categoria & conteúdo de um cartão existente.

## O que muda na tela

- Icon button "editar" abre o formulário pré-preenchido.
- Sugestões de categoria & mensagens de validação.
- Lista atualizada após salvar.

## Critérios de aceitação

- [ ] Icon "editar" abre o formulário com os valores atuais.
- [ ] Validação via CORE-04 (obrigatórios, trim, limites).
- [ ] Salvar persiste as alterações (WEB-02) & atualiza a lista.
- [ ] Cancelar não altera os dados.
- [ ] Mudança de categoria reflete no filtro de categoria (CORE-05).
