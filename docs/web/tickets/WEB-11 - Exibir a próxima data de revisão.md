# WEB-11 — Exibir a próxima data de revisão

**Tipo:** feature · **Épico:** Revisão · **Depende de:** WEB-01, CORE-02

## Resumo

Exibir em cada cartão a próxima data de revisão calculada.

## O que muda na tela

- Cada cartão mostra a próxima data de revisão (formatada em pt-BR).

## Critérios de aceitação

- [ ] Cada cartão exibe `dataProximaRevisao` formatada em pt-BR.
- [ ] O valor vem do cálculo de CORE-02 (não é recalculado na UI).
- [ ] Formato de data consistente em toda a lista.
- [ ] Atualiza após cadastrar, editar || marcar como revisado.

- CDUs: CDU-02 · HUs: HU-03 · RN: RB-01, RB-07 · RNFs: RNF-08
