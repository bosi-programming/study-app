# RNF-14 — Sem telemetria

**Categoria (ISO 25010):** Privacidade

## Requisito

- Nenhuma telemetria/analytics & nenhuma chamada de rede com dados do usuário.

## Métrica / critério de verificação

- Zero endpoints de analytics; zero requisições em runtime após o carregamento dos assets.

## Como verificar

- Inspeção de rede na aba Network.

## Relacionados

- RNFs: RNF-01 (persistência local), RNF-02 (offline)
