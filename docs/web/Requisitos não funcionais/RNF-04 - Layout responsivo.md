# RNF-04 — Layout responsivo

**Categoria (ISO 25010):** Usabilidade

## Requisito

- Layout responsivo com largura máxima de conteúdo de **1024px**.
- **40px** de padding lateral.

## Métrica / critério de verificação

- Conteúdo centralizado até 1024px; padding lateral de 40px (reduzido em telas pequenas).
- Sem scroll horizontal em viewport ≥ 360px.

## Como verificar

- Inspeção visual em larguras 360/768/1024/1440px.

## Relacionados

- RNFs: RNF-05 (espaçamentos)
