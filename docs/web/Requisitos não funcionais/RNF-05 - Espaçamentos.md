# RNF-05 — Espaçamentos

**Categoria (ISO 25010):** Usabilidade

## Requisito

Espaçamentos verticais conforme o sketch de UI:

- **40px** entre seções.
- **8px** entre cartões da lista.
- **20px** ao final da lista.

## Métrica / critério de verificação

- Gaps exatos via tokens/estilos do design system.

## Como verificar

- Inspeção de layout / snapshot visual.

## Relacionados

- RNFs: RNF-04 (layout), RNF-08 (design system)
