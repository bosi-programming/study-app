# RNF-02 — Funcionamento offline

**Categoria (ISO 25010):** Confiabilidade

## Requisito

- O app funciona **offline** após o primeiro carregamento.

## Métrica / critério de verificação

- Cadastrar, revisar, editar, excluir & filtrar funcionam sem conexão.

## Como verificar

- Teste manual com a rede desligada após o primeiro load.
