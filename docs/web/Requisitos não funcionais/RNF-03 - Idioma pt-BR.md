# RNF-03 — Idioma pt-BR

**Categoria (ISO 25010):** Usabilidade

## Requisito

- Toda a interface & mensagens estão em **pt-BR**.

## Métrica / critério de verificação

- 100% dos textos visíveis em pt-BR; nenhum texto hardcoded em outro idioma.

## Como verificar

- Revisão de textos & busca por strings.
