# RNF-11 — Compatibilidade de navegadores

**Categoria (ISO 25010):** Compatibilidade

## Requisito

- Suporte às **últimas 2 versões** dos navegadores com IndexedDB: Chrome, Edge, Firefox & Safari.

## Métrica / critério de verificação

- App carrega & opera nesses navegadores; feature detection p/ IndexedDB com mensagem de fallback.

## Como verificar

- Teste manual cross-browser.

## Relacionados

- RNFs: RNF-01 (IndexedDB)
